About

lanlink-desktop is the native desktop front-end for the LanLink daemon.

It shows live status from the daemon's local socket and forwards create/join requests to the coordinator. To start the data plane, run lanlinkd or use lanlinkctl on this machine.

  • Coordinator: configured via --coordinator
